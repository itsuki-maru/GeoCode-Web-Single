# 共通フォームの作成とレイヤ管理

共通フォームは、複数のマーカー・図形で再利用する入力項目のひな型です。PostgreSQL版・SQLite版のPC・モバイルで利用できます。

## 作成・編集・削除

1. ツールバーの「共通フォーム作成・管理」を開きます。モバイルでは上部のツールバーを開いて選びます。
2. 「作成」から「新しい共通フォームを作成」を押します。
3. フォーム名・説明・入力項目を設定し、必要に応じて共通のパスワードを設定します。
4. 「共通フォームを保存」を押します。
5. 作成済みのフォームは「一覧」から「編集」「削除」を選べます。「回答一覧」からそのフォームの回答も確認できます。

入力型と画像の制限は[公開入力フォーム](PUBLIC_FORMS.md)を参照してください。共通フォームを作成しただけでは、対象への適用や外部公開は行われません。

## 個別コピーとレイヤ管理の違い

| 適用方法 | 操作 | 共通フォームの項目変更 |
|---|---|---|
| 個別コピー | 対象の「入力フォーム設定」で共通フォームを選び、「共通フォームを使用する」→置換の確認→「フォーム設定を保存」 | 自動反映されません |
| レイヤ管理 | レイヤ一覧の編集アイコンから「レイヤ設定」を開き、「共通フォームを設定」で選択→「変更」・置換の確認 | 管理中の既存・新規のマーカーと図形に自動反映されます |

個別コピーはフォーム名・説明・入力項目を置き換え、保存するまで確定しません。対象の公開状態・URL・パスワードは維持します。

レイヤ管理を開始・変更すると、既存の対象別設定とパスワードを共通フォームの設定に揃えます。既存対象の公開状態・URLは維持し、新規対象は公開無効で作成します。確認画面の対象件数と置換内容を確認してください。空レイヤにも設定でき、以後の新規対象へ適用されます。

管理中の対象では、項目・適用元・個別パスワードを変更できません。公開のON/OFF、URLコピー・再発行、所有者の回答登録は利用できます。共通フォームの編集を保存すると、管理中の対象へ項目変更が反映されます。過去の回答・本文・メモ・画像は保持します。

## 所属レイヤの変更と設定解除

- 別の管理レイヤへ移動すると、移動先の共通フォームとパスワードへ置き換わります。
- 共通フォームが未設定のレイヤへ移動すると、適用済みの定義を個別設定として保持します。以後の項目変更は自動反映されません。
- 同じレイヤで通常編集を保存しただけでは、フォームを再適用しません。
- レイヤの「共通フォームを設定」を「未設定」にして「変更」を押し、確認すると、所属対象のフォーム設定を解除します。公開を無効にし、公開URLを失効させます。回答履歴・本文・メモ・画像は保持しますが、適用前の個別設定は復元しません。

## パスワード変更と削除の注意

共通フォームでパスワードを明示的に設定・再設定・解除すると、現在その共通フォームを適用元としている対象へ反映します。レイヤ管理中だけでなく、個別コピー先も含みます。個別コピー先の項目定義は変更しません。「変更しない」ではパスワードを維持します。保存前に表示される反映件数を確認してください。

レイヤで使用中の共通フォームは、対象が0件でも削除できません。先に該当レイヤの設定を解除してください。個別コピーのみで使用しているフォームは削除でき、適用済みの設定・回答履歴は残ります。
