# フォーム回答の登録・検索・編集

PostgreSQL版・SQLite版の両方で、所有者の入力と外部公開フォームからの回答を検索できます。本文・図形メモへの自由入力は分析対象になりません。分析の中心は検索・絞り込み・地図確認・CSV出力で、合計・平均などの集計画面はありません。

## 所有者が新しい回答を登録する

1. 地図オブジェクト一覧の対象名を押して編集画面を開きます。
2. 未設定の場合は「入力フォーム設定」で項目を設定します。
3. 「フォームで回答を登録」を押し、入力して「回答を保存」を押します。

保存済みフォームに項目があれば、外部公開が無効でも利用できます。登録ごとに新しい回答履歴が増え、回答内容をマーカー本文・図形メモにも追記します。既存回答の修正は後述の「編集」から行ってください。

## 回答一覧を開く

ツールバーの「共通フォーム作成・管理」→「フォームからの回答一覧と分析」を選びます。共通フォームの「一覧」にある「回答一覧」からは、そのフォームを選択した状態で開けます。PC・モバイルとも利用できます。

「すべての回答」は全履歴、「対象ごとの最新回答」は対象・フォームごとの最新1件です。最新1件を選んでから条件を適用するため、最新回答が条件に合わなくても過去の一致回答で補いません。投稿日時が基準で、過去回答を編集しても最新の順序は変わりません。

## 条件を編集して反映する

1. 「絞り込み」を開き、共通フォーム、対象名、回答日時を指定します。
2. 「詳しい条件」で適用元の版、対象種別、レイヤを指定できます。
3. 回答内容で検索する場合は共通フォームを選び、「条件を追加」で項目と比較条件を指定します。複数条件はすべてに一致する回答が対象です。
4. 「絞り込む」または「変更を反映」を押します。条件を編集しただけでは表示中の結果やCSVに反映されません。
5. 「表示する項目」で一覧に表示する回答項目を選びます。「詳細を見る」では投稿時のフォーム定義に沿った回答を確認できます。

| 状態 | 意味 |
|---|---|
| 未入力 | 投稿時に項目は存在したものの、値が未入力です |
| 項目なし | 投稿時のフォームにその項目がありません。後から追加した項目などが該当します |
| 0 | 数値の回答です。未入力ではありません |
| false（いいえ） | チェックボックスの回答です。未入力とは区別します |

フォームの版や項目の種類が異なる場合は、項目名だけで同じ回答と判断せず、詳細の投稿時定義を確認してください。投稿時の定義を持たない旧回答には、項目IDなどで表示する場合があります。

## 地図で確認・CSV・印刷

「地図で確認」で一覧の全ページの該当対象を表示します。同じ対象は重複させず、最大10,000対象です。地図では回答条件、対象名、レイヤなどで追加の絞り込みができます。回答条件を変更したら「絞り込み」で反映し、「地図条件を解除」で一覧から渡した範囲に戻します。

表示位置・形状・名前などは現在の情報で、回答時点の地図を復元するものではありません。ポップアップの「フォームからの回答」は対象に保存された全回答の修正後の内容を表示し、検索に一致した回答だけには限定しません。

| 操作 | PC | モバイル |
|---|---|---|
| 一覧の「CSV出力」 | 対応 | 対応 |
| 回答地図での追加絞り込み | 対応 | 対応 |
| 回答地図で絞り込んだ対象の「CSV出力」 | 対応 | 非対応 |
| 回答地図の「地図を印刷」・PDF出力 | 対応 | 非対応 |

一覧CSVは反映済み条件の全ページが対象です。PCの回答地図CSVは、その地図で絞り込んだ対象を出力します。CSVは最大10,000回答・回答項目200種類です。上限を超える場合は条件を絞ってください。

モバイルの回答確認用地図には「機能を表示／機能を非表示」があり、地図上の操作部の表示を切り替えられます。PCの印刷手順は[地図印刷](MAP_PRINTING.md)を参照してください。

## 既存回答を編集する

1. 回答一覧の「編集」、または「詳細を見る」→「回答を編集」を押します。
2. 投稿時のフォーム定義で値を修正します。現在のフォーム定義へ置き換わるわけではありません。
3. 画像は保持・差し替え・回答からの削除を選べます。
4. 「回答を更新」を押します。分析用の値と本文・図形メモの回答部分を連動して更新します。

回答件数と投稿日時は変わりません。修正前の値を別回答として残す変更履歴機能ではありません。自由記述制限がONでも回答は編集できます。画像を差し替え・削除しても、旧画像ファイルは自動削除しません。

投稿時の定義がない旧回答は閲覧のみです。旧本文との対応が曖昧な場合は、元の本文と回答部分を確認し、残す自由入力を指定してから保存します。同時編集などで競合した場合は、画面の案内に従って再読み込みし、最新内容を確認してから修正し直してください。

## 自由入力・回答部分と削除

通常のオブジェクト編集の本文欄と、地図上の図形編集のメモ欄は自由入力部分を編集します。フォーム由来の内容は確認できますが、修正は回答一覧から行います。レイヤの[自由記述制限](LAYERS_AND_MARKERS.md#自由記述の制限)がONの場合は、フォームで登録・編集してください。

マーカー・図形を削除すると、編集済み・過去分を含む全回答も削除されます。共通フォームの定義と画像ファイルはこの連動削除に含まれません。必要なデータは先に[JSON出力](DATA_IMPORT_EXPORT.md)してください。
