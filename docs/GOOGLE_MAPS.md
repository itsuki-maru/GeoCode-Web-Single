# Google背景地図と経路検索

Google Map Tiles APIの道路・衛星・地形背景を表示する。経路検索は、ログイン後のPC・モバイルの通常地図とPCの全画面地図で、Google背景を選んだときに利用できる。

## 導入

1. アプリの更新後、起動時マイグレーション30で `google_routes_settings` を作成する。登録済みの背景、暗号化済みのキー、共有地図をそのまま使用できる。経路検索の初期設定は無効。
2. 初回はGoogle Cloudで課金とMap Tiles APIを有効にし、Google Maps APIキーを作る。キーのAPI制限にMap Tiles API、アプリケーション制限にサーバーの外向きIPを指定する。管理画面の「Google Maps設定」の「Map Tiles API」でキーと言語・地域・利用上限を保存し、「背景地図設定」でGoogleの背景を登録する。
3. 経路検索を使う場合は、Google Cloudの同じプロジェクトでRoutes APIを有効にし、既存キーのAPI制限にMap Tiles APIとRoutes APIの両方を指定する。管理画面の「Routes API」で「経路検索を有効にする」をオンにして保存する。キーを更新すると両APIに反映する。

APIキーはSQLiteに暗号化して保存する。通常は実行時設定JSONの `tile_settings_encryption_key` を暗号鍵として使用する。起動時に `GOOGLE_MAPS_ENCRYPTION_KEY` があれば優先する。バックアップ時は本体DBと設定JSON、環境変数で指定した場合はその暗号鍵を保管する。

## 利用する

1. Google背景を選び、マーカーまたは図形のポップアップで「この場所への経路」を押す。マーカーの目的地は登録座標、図形ではクリックまたはタップした地点になる。
2. 現在位置と目的地をGoogleへ送信することを確認し、ブラウザーの位置情報利用を許可する。同じ地図で60秒以内に取得した位置を優先して使用する。
3. 経路線・概算所要時間・距離を確認する。「徒歩」に切り替えると同じ目的地への徒歩経路を検索する。車の経路はリアルタイムの交通状況を考慮しない。

背景を切り替えるか経路を消すと表示を終了する。PCの通常地図と全画面地図では、印刷プレビューで元のGoogle背景を表示できた場合に、経路線と経路パネルを再現する。印刷プレビュー上でパネル位置を調整できる。位置情報と経路はDBに保存せず、共有URLや保存地図にも含めない。

## APIと利用上限

| API | 用途 |
|---|---|
| `GET/PUT /admin/google-maps-settings/routes` | 管理者による経路検索の有効化・利用上限の取得と保存。`revision` で同時編集を検出する |
| `POST /google-maps/context` | 地図の閲覧権限を検証し、タイル取得用のgrantと `routesEnabled` を返す。一時共有・ライブ地図の `routesEnabled` は `false` |
| `POST /google-maps/routes/compute` | アカウント認証と登録済みGoogle背景を検証し、`DRIVE` または `WALK` の経路を取得する |

経路検索は背景タイルとは独立に、プロセス全体で既定60回/分（設定範囲1〜3,000回/分）、アカウントごとに最大10回/分、同時上流要求8件に制限する。経路計算ルーターの応答に `Cache-Control: no-store` を付ける。

自動テストは模擬HTTP上流で、車・徒歩の要求、結果の変換、キー更新、認証、利用上限と移行を検証する。アプリ起動後の受入確認は、管理画面で経路検索を有効にし、国内の地点で車・徒歩、背景切替、PCの印刷プレビューを確認する。実Googleへの要求には有効なキーと課金設定が必要。
